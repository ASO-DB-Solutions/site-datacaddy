# 2026-09-11 — datacaddy.co goes live, and then gets a way to be answered

**Source**: sixteen commits, `d36d026` through `a1e771f` (14:02–19:21); pull requests [#1](https://github.com/ASO-DB-Solutions/site-datacaddy/pull/1) through [#6](https://github.com/ASO-DB-Solutions/site-datacaddy/pull/6). The Netlify account and the DNS records were created by the owner outside the repository, so the moment the site actually went live leaves no commit of its own — it was verified directly against the live address instead.

**The site is online at [datacaddy.co](https://datacaddy.co)**, with a valid certificate, both
languages answering, and search engines still asked to stay away. That last part is deliberate:
the site is live but not launched, and the two are being kept apart on purpose.

By the end of the day it also had a working contact form, a privacy notice, and its owner's name
in the footer.

## The domain turned out to constrain the plan

The intention was to move the domain's DNS into Microsoft, alongside the company's other
services. Checking rather than assuming closed that option twice over.

`datacaddy.co` is registered at **Cloudflare**, and Cloudflare requires domains registered with it
to keep using its own name servers. Moving DNS to Microsoft would have meant transferring the
registration elsewhere first — weeks of work and a fee before anything could be configured.

It also turned out to be unnecessary. **Microsoft 365 does not host DNS**; it only specifies which
records must exist, and those work perfectly well where the domain already lives. The requirement
behind the request — a working `info@datacaddy.co` — is satisfied without moving anything.

Worth noting separately: `datacaddy.com` belongs to someone else. The designer's export used
`hello@datacaddy.com` as the site's contact address, which would have pointed customers at a
domain the company does not control. Corrected when the form shipped.

## What a public repository publishes

The code is public, which was a deliberate choice with real benefits. What had never been written
down is what that actually exposes, so the whole surface was audited.

**No secret was found exposed**, and the audit specifically confirmed that the workstation name,
the production server name, the bot's address and every IP address are absent. What it did find is
five things public by default rather than by decision — including a personal email address
permanently attached to every commit, which cannot be corrected retroactively.

Three facts from that review are the kind people reliably get wrong. A "secret" stored in a
website's build settings is written straight into the file every visitor downloads — the hosting
control panel calls it a protected setting, and it is not. Every security certificate ever issued
for a domain is recorded in a public, permanent register, so a private-sounding address like
`staging.datacaddy.co` would be discoverable minutes after it existed. And on a public project,
the logs of automated checks are readable by anyone.

## The assessment request became a form

The call to action was a link that opened the visitor's email program. It is now a real form, in
both languages, with the privacy notice Brazilian law requires shown where the data is actually
collected rather than buried on another page.

Two things about it are worth knowing because they look like faults and are not. The form
**silently discards anything filled in faster than a person plausibly could** — an anti-robot
measure — and shows the same confirmation either way, so a hurried test appears to succeed while
going nowhere. And the form's fields are mirrored by a hidden copy in the page's markup, which
looks like dead code and is what makes the whole thing work; removing it would break submissions
with nothing else appearing wrong.

## Decisions stopped being folklore, and the project got a record of itself

Three decision records were written: leaving the Figma tooling, giving each language its own
address, and choosing Netlify. The Netlify record spends most of its length on the options that
lost, because they were close — one was the option the company is already set up for, and it lost
on balance rather than on capability.

The project also gained a licence, an inventory of where every image and typeface came from and
what licence it carries, and the recipe that produced the optimised images — which had been lost,
leaving files in the repository that nobody could have reproduced.

And it gained this devlog. An earlier decision said a one-page site would not justify one. Two days
in, that was plainly wrong: the day above contains half a dozen things a stakeholder would want to
follow, none of them legible without reading commit messages.

## Two mistakes, both recorded rather than tidied away

A translation gate was built so that a missing Portuguese string fails the build. The first version
demanded every translation be **identical to the English**, which is the opposite of the point; it
was nearly "fixed" by adding more machinery rather than removing the line that caused it.

And a verification command used a wildcard in a web address, which does not work the way it does on
a filesystem. It fetched nothing, found nothing, and reported success. The answer happened to be
right; the evidence was worthless. Both are written into the record because the second kind of
mistake — a check that passes without checking — is the one worth recognising again.

## The day ended on the footer

The form moved beside the pitch rather than under it, which needed the background darkened so its
labels stayed legible. The footer now names **ASO Tech Global LLC**, the entity that owns the web
project — the site targets the United States market, which is why the US entity owns it rather
than the Brazilian company that owns the code repository. Both are now recorded, along with the
boundary between them.

## Still outstanding

- **DKIM and DMARC** for `datacaddy.co`, and the `info@datacaddy.co` mailbox itself.
- **The form's email notification**, which is one setting — submissions are being captured now and
  nobody is being told.
