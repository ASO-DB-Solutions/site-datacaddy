# 2026-09-10 — The site stops being a designer's export and becomes a project

**Source**: three commits, `43037da` through `f6989b9` (18:23–18:59). Much of the day happened in
GitHub settings pages, an SSH key exchange and a long read of the designer's export, none of which
leaves a trace in commit history, so this entry also draws on what was verified directly against
the repository and the filesystem.

The designer's handover arrived as a **Figma Make** export — not the HTML and CSS a design export
usually means, but a working React application wired to Figma's own hosting. It built and it
worked. By the end of the day it was in version control, stripped of the parts that only made
sense inside Figma, and a third the size.

## What the export actually was

The folder contained a complete React 19 application: Vite, TypeScript, Tailwind. It also
contained a good deal that should never reach a public repository — 2,318 lines of machine-generated
code nothing referenced, 3.28 MB of unoptimised images, fonts fetched at page load from Figma's
own servers, and an instruction to search engines not to index the site, shipping silently.

The obvious move was to commit it as delivered and tidy up afterwards. That was rejected, and the
reason is the one thing from today most worth remembering: **a public repository's history is
permanent.** A file committed once and deleted next week stays downloadable forever, by anyone,
including in copies already taken. Tidying afterwards would have left the 2.28 MB texture and the
dead code in the record for good. So the first commit was assembled clean instead, file by file.

## The find that changes the Portuguese edition

One of those 2,318 "dead generated" lines turned out to be the **original Portuguese copy deck**.
The design was written in Portuguese first, and the English on the page today is derived from it.

That reframes the bilingual work entirely: the Portuguese edition is largely a recovery of the
source rather than a translation to be commissioned. It also means neither language can be
regenerated from the other — both are authored text.

It is also the clearest argument for having read the export rather than importing it. Had the
folder been committed and cleaned later, the Portuguese source would have been deleted by someone
who reasonably believed it was machine output.

## Three megabytes became a quarter of one

The images went from 3,274 KB to 250 KB, with no visible change.

Most of that is one file. The site's hero texture was 2.28 MB, and it is drawn using a blending
mode whose behaviour makes a four-channel image mathematically equivalent to a one-channel one in
this particular use. Exploiting that took it to 28.5 KB — a 99% reduction that is not a quality
compromise, and which was measured rather than assumed before being accepted.

## The rest of the day

The fonts now ship with the site instead of being fetched from Figma at page load, which removes
a dependency on a third party staying available. The formatter that came with the export was
replaced, having been caught **corrupting the source** — it deleted a character from a type
declaration, producing invalid code that the build accepted anyway. Only the stricter checker
caught it, which is why that check is now mandatory before anything merges.

The day closed with a runbook, in English and Portuguese, for putting the site online — written
before doing it, so the steps are a plan rather than a reconstruction.

Two mistakes are worth recording. A key was generated, handed over for registration, and then
regenerated under a better naming convention — invalidating the one already registered and costing
the owner two rounds of the same task. And ten files were committed marked as executable, because
they came across from a Windows-mounted folder where everything claims to be; corrected the same
evening.
